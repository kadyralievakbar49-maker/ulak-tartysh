# Улак Тартыш

Веб-портал об игре «Улак Тартыш»: новости, команды, игроки, лошади, матчи и документы Федерации. Интерфейс поддерживает русский и кыргызский языки.

## Возможности

- Новости, фотоальбомы и видео.
- Команды, игроки, лошади и трансферы.
- Расписание матчей, архив, турнирные таблицы и статистика.
- Правила, регламенты и документы для скачивания.
- Личный кабинет, сохранённые материалы и заявки на добавление лошадей.
- Панель администратора для управления содержимым и пользователями.
- Подтверждение почты и восстановление пароля через SMTP.

## Технологии

Python, Flask, SQLite, Jinja2, HTML, CSS и JavaScript. Для обработки изображений используется Pillow, для защиты форм — Flask-WTF. Docker-образ основан на Python 3.12.

## Локальный запуск

Команды для Linux/macOS с Python 3.12:

```bash
git clone https://github.com/kadyralievakbar49-maker/ulak-tartysh.git
cd ulak-tartysh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В файле `.env` установите собственные `SECRET_KEY` и `ADMIN_PASSWORD`, затем запустите приложение:

```bash
python app.py
```

Сайт: <http://127.0.0.1:5002>. Панель администратора: <http://127.0.0.1:5002/admin>. Для входа используйте пароль из `ADMIN_PASSWORD`.

При запуске через `python app.py` приложение создаёт таблицы и обновляет схему базы данных. Рабочая база и загруженные пользователями файлы не входят в репозиторий, поэтому локальный запуск не переносит содержимое действующего сайта.

## Настройки

| Переменная | Назначение |
| --- | --- |
| `SECRET_KEY` | Секретный ключ сессий и защиты форм |
| `ADMIN_PASSWORD` | Пароль панели администратора |
| `DATABASE_PATH` | Путь к SQLite; по умолчанию `database.db` |
| `PORT` | Порт локального сервера; по умолчанию `5002` |
| `DEBUG` | Режим отладки; для публичного сервера задайте `false` |
| `PUBLIC_BASE_URL` | Внешний адрес сайта для ссылок в письмах |
| `SMTP_HOST`, `SMTP_PORT` | Сервер и порт почты |
| `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` | Данные отправителя |
| `SMTP_USE_TLS`, `SMTP_USE_SSL` | Настройки шифрования SMTP |
| `EMAIL_CONFIRMATION_TTL_HOURS` | Срок действия подтверждения почты |
| `SESSION_COOKIE_SECURE` | Передача cookie только по HTTPS; включайте при работе через HTTPS |

Полный пример настроек находится в [.env.example](.env.example). Для отправки писем укажите реальные параметры SMTP. Не публикуйте `.env` и пароли.

## Docker

Подготовьте `.env` по инструкции выше. Для запуска только веб-приложения:

```bash
docker compose up --build -d web
```

Сайт будет доступен по адресу <http://127.0.0.1:5000>. Установите соответствующий `PUBLIC_BASE_URL` в `.env`.

Файл Compose также содержит сервис `backups` для периодического резервного копирования. Перед его запуском проверьте имя образа в `docker-compose.yml` и права записи в каталог `backups`.

## Проверки и резервное копирование

Проверка данных и создание резервной копии:

```bash
python scripts/check_site_data.py
python scripts/backup_site.py
```

Тесты используют временную копию локального файла `database.db`. После первоначального запуска приложения их можно выполнить командой:

```bash
python -m unittest tests.test_portal_features
```

База данных, `.env`, каталог `backups/` и пользовательские загрузки `static/uploads/` исключены из Git. Для переноса действующего сайта их нужно переносить отдельно.

## Структура проекта

```text
app.py                 Маршруты и настройка приложения
init_db.py             Отдельный скрипт подготовки базы с начальными данными
templates/             Шаблоны страниц и панели администратора
static/                Стили, JavaScript, изображения и документы
utils/                 Дополнительные функции портала
scripts/               Проверка данных и резервное копирование
tests/                 Проверки функций портала
docs/                  Документация и отчёт проверки данных
```
