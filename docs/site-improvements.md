# Обновления портала

Избранное доступно через звёздочку в шапке и личный кабинет. Лошадь, игрока или команду можно сохранить на странице профиля. Подписка на команду показывает ближайшие игры в кабинете; календарь ICS можно импортировать в приложение календаря. Письма-напоминания о матчах не подключены.

Пользователь подаёт объявление через кабинет. Оно хранится отдельно от каталога до одобрения. Администратор открывает «Объявления на проверку», проверяет данные и публикует или отклоняет запись с комментарием. Повторное одобрение не создаёт дубликаты.

В админке лошади появились владелец, регион, достижения, связанный игрок и объяснение шкалы показателей. У новости можно выбрать команду и архивный матч. Существующие значения не подменяются догадками.

Восстановление пароля доступно из формы входа. Одноразовая ссылка действует 30 минут; после смены пароля старые пользовательские сеансы завершаются. Регистрация и восстановление используют существующие SMTP-настройки. Доставка проверена 06.10.2026: тестовое письмо отправлено через действующий SMTP, пользователь подтвердил получение во входящих. Автоматические тесты не отправляют письма.

## Проверки

```bash
PYTHONDONTWRITEBYTECODE=1 python -m unittest tests.test_portal_features -v
python scripts/check_site_data.py --output docs/data-audit.json
```

В админке есть актуальная проверка файлов и неполных карточек. Отчёт фиксирует отсутствующие файлы; он не удаляет записи. Необходимо вернуть исходные фото/видео или исправить ссылки через админку. Для отсутствующих файлов посетителю показано понятное состояние вместо сломанной загрузки.

## Резервная копия

```bash
python scripts/backup_site.py --database database.db --output backups
```

Архив содержит согласованную копию SQLite, `static/uploads` и `static/documents`; секреты из `.env` не копируются. Каталог резервных копий исключён из Git. В `docker-compose.yml` добавлен сервис `backups`: при запуске Docker Compose он делает копию каждые 24 часа и хранит последние 14 архивов. Сервис включён 06.10.2026; первая копия успешно создана и проверена. Он работает отдельно от web без сетевого доступа; исходные данные подключены только для чтения. Для запуска без Docker можно использовать планировщик сервера либо `python scripts/backup_site.py --interval-hours 24 --keep 14`. Копирование медиа не блокирует редакторов: для полного совпадения базы и файлов выполняйте резервирование в период без загрузок/удалений файлов.

Восстанавливать сначала в отдельный каталог и проверять `PRAGMA integrity_check`; для замены рабочей базы остановить приложение, сохранить текущую копию, затем перенести базу и файлы из выбранного архива. Настройки `.env` хранятся отдельно.

## Перед публичным запуском

Проверить реальные контакты, цены, характеристики и принадлежность фотографий; восстановить файлы из отчёта; проверить доставку подтверждения и восстановления пароля. Настроить домен, HTTPS, `PUBLIC_BASE_URL`, `DEBUG=false`, `SESSION_COOKIE_SECURE=true`, уникальный `SECRET_KEY` и пароль администратора. Наличие SMTP-конфигурации не подтверждает доставку.
